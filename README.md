# Priority Planner & Execution Dashboard

An intelligent, interactive weekly planner and timetable web application built with Python (Flask). It blends structured time-blocking with personalized priority color-coding, in-flight task reschedule management, and aggregate productivity reporting.

---

## Key Features

- **Custom Priority Schema & Palette:** Define custom priority tiers (e.g., Urgent, Core Work, 1-to-1, Admin) and select custom hex colors with an integrated visual key.
- **Visual Timetable Grid:** Faithfully mirrors multi-slot weekly timetables with room, subject, and time-block tags.
- **Active Execution & Checklists:** Check off tasks live directly from the weekly grid.
- **Struggle / Reschedule Flow:** One-click re-routing for incomplete or delayed tasks to keep schedules realistic without guilt.
- **Multi-Horizon Reporting:** Daily, weekly, and monthly aggregate analytics breaking down planned vs. completed hours and priority distribution.
- **Export Ready:** Clean layouts formatted for screen viewing and print/PDF downloads.

---

## Tech Stack

- **Backend:** Python (Flask), Gunicorn
- **Templating Engine:** Jinja2
- **Deployment Platform:** Render
- **Version Control:** Git & GitHub
